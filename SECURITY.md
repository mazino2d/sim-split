# Security Policy

SimSplit works fully offline and keeps all data on the device. There is no
server or account, so most risks are in the app itself, its dependencies and
the CI that builds and publishes it.

## Supported versions

Only the latest release on Google Play gets security fixes.

## Reporting a vulnerability

Please report privately through
[GitHub private vulnerability reporting](https://github.com/mazino2d/sim-split/security/advisories/new).
Do not open a public issue.

Include what you found, how to reproduce it and the app version. You should get
a reply within 7 days. Once a fix ships, the advisory is published with credit
to you unless you prefer otherwise.
